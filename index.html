Your infrastructure. Your keys. Your call.

Local-first, cloud-optional

Talks natively to LM Studio and Ollama on your own network. OpenAI, OpenRouter, DeepSeek, Moonshot, Zhipu, Gemini and Qwen are there when you want them — never required.

Agent2Agent (A2A)

Discover and message remote autonomous agents over your own Tailscale mesh. Peer tables give one profile several gateway identities; agent "arms" let a regular chat model call a remote agent as a tool and relay the answer in-persona.

Nord, Dracula, Catppuccin, Gruvbox, Tokyo Night, Rosé Pine, One Dark, Monokai and more, plus Material You dynamic color and true-black AMOLED — each a faithful recreation, not a filter.

Voice, vision, documents

Speech-to-text and read-aloud, image attachments for vision models, PDFs extracted and inlined on-device — plus eight agent personas to talk to before you've written a single system prompt.

02Guarded守り

What's actually protected, layer by layer

Not a blanket claim — here's exactly what's encrypted, what isn't, and why.

Credentials

AES-256 · Keystore

API keys and A2A tokens live in the Android Keystore via EncryptedSharedPreferences (AES-256), hardware-backed where available — excluded from cloud auto-backup entirely.

Conversation history

SQLCipher · at rest

The local database — every conversation, every message — is SQLCipher-encrypted at rest behind a random key generated on-device and stored the same Keystore-backed way as your API keys.

Backups & exports

AES-256-GCM

The full backup, and a profile export that includes keys, both go through the same AES-256-GCM envelope behind a passphrase you set — never stored, so losing it loses the file. Exporting profiles without keys carries no secret, so it stays plain JSON.

Network transport

HTTPS · TOFU pin

HTTPS to any cloud provider, as usual. LM Studio, Ollama and A2A default to plain HTTP on your own LAN — matching how those servers actually run — but an https:// URL works too, self-signed certificate included: trust it once by its fingerprint, the same way SSH trusts a host key, and a certificate that changes afterward is rejected rather than silently re-accepted.

What this isn't

Not end-to-end

End-to-end encrypted. The model has to read your plaintext prompt to answer it — no chat client talking to an LLM can honestly claim otherwise.
